我这边建议PPT要：
1.突出重点！画图用色块，文字着重描述等
2.用点动画，搞美观、漂亮点
3.一定要提前写稿、背稿，反反复复背稿！确保7分钟内可以流畅的念完PPT
4.要知道PPT每一页的内容与原理，应对好各种刁难问题。否则答辩会被说教的。
